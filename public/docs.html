01 / OVERVIEW

A workspace in development.

LeadMASTER is being built as a single-user workspace for transactional and campaign email. The responsive landing and login interfaces are available in the preview. Authentication, the dashboard, campaigns, public email API, AI and MCP integrations are not yet operational.

The current preview is not production-ready and cannot send email.
02 / AUTHENTICATION

Secure sign-in.

The login interface supports username or email, password, a Cloudflare Turnstile placeholder and an email-code step. The authentication service and sessions are not implemented; sign-in remains disabled.

The planned backend must validate the configured admin allowlist, password and Turnstile server-side, then issue a time-limited, single-use code and secure session. Passwords and service credentials must remain in Cloudflare secret storage.

03 / EMAIL API

Developer access.

There is no public sending API yet. Existing code contains internal helpers for Turnstile verification, AWS SES SMTP and message queueing; they are not public authorization boundaries.

Do not use the preview to submit messages or credentials. A future API requires authentication, authorization, durable acceptance, abuse protection and complete documentation.

04 / QUEUE & DELIVERY

Thoughtful delivery.

The repository includes a queue consumer and a single coordinator that manages SMTP attempts in the background. This is code under development, not a deployed sending service; it has only been tested against mocked boundaries.

Queued acceptance is not delivery. If an SMTP outcome is uncertain, the coordinator pauses instead of automatically resending. Recovery, monitoring, queue bindings and live AWS tests are still required.

05 / SECURITY & RELEASE

Built with care.

Before production, LeadMASTER needs a reviewed authentication service, authorization, secure credential and session handling, durable sending and recovery, consent and suppression controls, observability, a verified sender, and end-to-end tests in a dedicated environment.
