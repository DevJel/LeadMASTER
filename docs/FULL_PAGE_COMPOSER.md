# Dashboard composer and Campaigns navigation

Compose opens inside the existing scrollable dashboard content area, retaining desktop navigation, header and mobile bottom navigation. The panel uses the dashboard theme and neutral controls; View emails returns to the email list. Unsaved changes require confirmation before leaving. The user-facing send status reports queue acceptance and skipped recipients when known, not the internal queue rate. Acceptance is not delivery.

The composer supports up to 500 manually entered or browser-extracted recipient addresses from multiple CSV/text files. It ignores non-email text and removes duplicates; extraction does not verify mailboxes or save contacts and groups. Account-owned templates can be saved, listed and inserted through `/api/admin/templates`; editing and deleting templates are not implemented. HTML can be pasted into the composer, including ordinary HTML exported from an email editor; a plain-text alternative is required. Preview is sanitized and sandboxed, blocks external resources and can differ from delivered HTML. Zoho-specific compatibility has not been verified.

Optional HTML sends use the existing SES SMTP transport as multipart/alternative, not SESv2 Content.Raw. `ADMIN_HTML_SEND_ENABLED=true` is required to permit HTML requests; default is fail-closed without submitting a message. Do not enable it before migrations 0009 and 0010 and the compatible queue consumer are deployed and verified. Old consumers would otherwise omit HTML. Migrations, deployment and the flag require separate production approval after staging, backup and rollback review. Never deploy the 0009 consumer until 0009 is applied and queued/unknown records are reconciled. Existing login and SMTP credentials are unchanged.

The Campaigns label currently shows recent sends and immediate sending only. Saved campaigns, groups, scheduling, attachments, durable drafts, progress tracking and reliable end-to-end idempotency remain unavailable. Uncertain outcomes must not be blindly retried. Run full browser, accessibility, MIME and authenticated staging tests before release.
