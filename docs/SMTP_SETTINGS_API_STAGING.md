# External SMTP settings API — staging only

`externalSmtpSettingsRoute` is not mounted in the Worker. It offers account-scoped list/create/replace/revoke and per-connection LeadMASTER activity reads once it is safely wired. It requires the authenticated configured administrator and checks same-origin for writes; encrypted credentials and sender secrets are never returned. Configuration saves remain unverified. A missing encryption key fails closed. No route for testing or sending exists yet: the SMTP probe cannot be exposed until its injected socket factory enforces destination policy, DNS-rebinding defenses and certificate verification.

Integration requires a managed encryption key and keyring, rate limits, credential rotation and recovery, connection-revision-safe queue dispatch, read-only monitoring semantics for revoked connections, complete failure and authorization tests, real Cloudflare D1 and SMTP test-server verification, and TypeScript dashboard and Android integration. The separate migrations are not applied. No live API, UI, or Android source changes are made by this staging module. Do not deploy or apply migrations until the complete feature is reviewed and verified.
