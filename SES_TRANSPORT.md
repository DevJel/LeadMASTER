# SES SMTP transport

This is a transport helper, not an application or a deployed service. The Queue coordinator calls it internally; an experimental public HTTP producer can enqueue messages only when explicitly enabled, but it is disabled by default and not production-ready. Production use requires authenticated, authorized application endpoints, sender verification, an approved Cloudflare account, durable send-state/idempotency, rate limits, observability, security review and a real SES integration test.

- `src/ses-smtp.mjs` exports `sendSesEmail`. Supply `connect` from `cloudflare:sockets` within a Worker handler, not global scope.
- For the requested Sydney region, the SES endpoint is `email-smtp.ap-southeast-2.amazonaws.com`; the requested sender is `noreply@leadmaster.jelvan.pro`. Sender identity verification and production SES access have not been confirmed. Configure `SES_FROM_EMAIL` as the verified sender. Store `SES_SMTP_HOST`, `SES_SMTP_USERNAME` and `SES_SMTP_PASSWORD` as Worker secrets or Secrets Store bindings; all three support bindings with `get()`. Do not commit or expose their values. An empty Cloudflare Secrets Store named `leadmaster-secrets` was created; its entries and Worker bindings still need provisioning. See [AWS SES endpoints](https://docs.aws.amazon.com/general/latest/gr/ses.html).
- The module uses implicit TLS on port 465, authenticates only after TLS, limits the input to one text-only recipient and message, and sends no automatic retries. The caller must enforce authorization, sender policy, throttling and durable per-message state.
- An `accepted` response means SES accepted the message for processing, not that the recipient received it. An `unknown` error means SES may have accepted it: reconcile before any retry to avoid duplicates. `not_accepted` indicates rejection or failure before the DATA phase.
- Run local deterministic tests with `node --test`. These tests use mock sockets; they do not prove Cloudflare runtime compatibility, SES delivery, sender verification, or production readiness.
